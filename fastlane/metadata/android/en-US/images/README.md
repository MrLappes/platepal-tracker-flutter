# Store image assets

The maintainer will add the actual app images here before publishing. Expected files:

- `icon.png`: 512 x 512 px store icon.
- `featureGraphic.png`: 1024 x 500 px feature graphic.
- `phoneScreenshots/1_*.png`, `phoneScreenshots/2_*.png`, etc.: real Android phone screenshots in display order.

Use screenshots from the app without personal data or API keys. This directory intentionally contains no image placeholders.
